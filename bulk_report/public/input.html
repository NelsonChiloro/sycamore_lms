Node Batch Tool

Bulk Loan Date Correction

Paste the affected loan numbers, then submit one batch. The server reads each loan's existing stored loan date automatically, rebuilds repayment schedules using the same product rules as the legacy system, and restores any posted payments by installment number so paid entries are not lost.

Use one loan number per line. The system will fetch and record the loan date already stored on each loan automatically, so users do not need to type any dates here. For monthly cutoff products, the effective schedule date may still land on month start or month end according to existing loan rules.
